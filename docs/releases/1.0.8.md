# Numera 1.0.8

Release preparation: 4 November 2026.

This release improves provider error handling, permission recovery, reconnection and action replay, decimal input, keyboard focus, row controls, and UI performance. It includes regression tests and reproducible build instructions.

The repository has been cleaned of historical test captures, development archives, local reports, and one-off diagnostics. Runtime and source archives are provided separately, with SHA-256 checksums. Store descriptions are available in English and Russian.

Requires Firefox Desktop 140+. The runtime ZIP is unsigned and supports temporary installation through `about:debugging`; permanent installation in Firefox Release/Beta requires Mozilla signing. This GitHub release does not imply AMO approval.

Rates are informational and subject to provider availability. See PRIVACY.md for external requests and VERIFICATION.md for test coverage and limitations.
