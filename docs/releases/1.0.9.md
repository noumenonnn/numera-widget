# Numera 1.0.9

16 November 2026 · Firefox Desktop 140+ · Chrome 120+

Numera now includes separate Firefox and Chrome packages, a refreshed icon, and updated store screenshots.

- Convert a selected price on an HTTP(S) page into your main currency, even with the popup closed. Reload existing pages after updating.
- Enter amounts with country names or abbreviations in English or Russian, and choose a currency when the country has more than one supported option.
- Compare fiat and crypto in one list, with improved search, quick rates, refresh feedback, and Undo.
- Recover background connections and saved actions more reliably, with clearer quote timestamps and cached-rate handling.

- `numera-1.0.9.zip`: Firefox package for Mozilla submission or temporary installation. This GitHub archive is unsigned.
- `numera-1.0.9-chrome.zip`: Chrome Web Store submission package; extract it to install through **Load unpacked** in developer mode.
- `numera-1.0.9-source.zip`: matching readable sources, lockfile, local tooling patches, and reviewer build instructions.
