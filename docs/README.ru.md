Firefox уже доступен в магазине. Кнопка Chrome пока без ссылки.

Версия 1.0.9. Firefox Desktop 140+ и Chrome 120+. Валюты и криптовалюты в компактном окне на панели браузера: несколько строк для сравнения, поиск, перестановка и отмена удаления, русский и английский интерфейс, светлая и тёмная темы. При вводе суммы можно использовать названия стран и сокращения на русском и английском; при неоднозначности расширение предложит выбрать валюту.

Курсы: Frankfurter, Binance и Kraken. Расчёты выполняются локально с точностью до 50 значащих цифр. Суммы и настройки не отправляются разработчику; сторонние API получают обычные сетевые метаданные. Подробности: [PRIVACY.md](../PRIVACY.md).

Выделите на HTTP(S)-странице сумму с валютой (например, `30 USD`, `$30` или `30 долларов`) — рядом появится пересчёт в основную валюту из настроек, даже при закрытом окне Numera. Светлая и тёмная темы следуют настройкам расширения. Обычные числа и поля ввода игнорируются. После обновления расширения перезагрузите уже открытые страницы; на защищённых страницах браузера функция недоступна.

## Установка

Установите подписанное расширение из [Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/numera-widget/). Обновление до 1.0.9 появится в магазине после проверки Mozilla; версия в магазине может отличаться от версии GitHub.

Для временной установки [скачайте релиз](https://github.com/noumenonnn/numera-widget/releases/tag/v1.0.9), распакуйте `numera-1.0.9.zip`, откройте Firefox → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» и выберите `manifest.json`. Установка действует до закрытия Firefox.

Для **Chrome** скачайте и распакуйте `numera-1.0.9-chrome.zip` из того же релиза, откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите распакованную папку. Установка сохраняется после перезапуска, пока папка доступна. Публикация в Chrome Web Store ещё не выполнена.

## Сборка

Для локальной сборки Chrome выполните `npm ci` и `npm run build:chrome`, затем выберите `dist-chrome/` при загрузке распакованного расширения. Команда `npm run package:chrome` создаёт `artifacts/numera-1.0.9-chrome.zip` для отправки в магазин.

Node.js 24.15.0, npm 11.6.1:

```sh
npm ci
npm run verify
npm run package
npm run package:chrome
npm run package:source
```

Сборка Firefox находится в `dist/`, Chrome — в `dist-chrome/`. Архивы расширения и отдельный архив исходников находятся в `artifacts/`. `npm run verify` проверяет обе сборки. Описание для магазина: [STORE_LISTING.md](STORE_LISTING.md), инструкция подачи: [PUBLISHING.md](PUBLISHING.md).

Курсы справочные, зависят от доступности источников и могут устаревать. Не используйте их как торговые котировки. Расширение не работает в приватных окнах.
