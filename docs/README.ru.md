# Numera — конвертер валют для Firefox

Версия 1.0.8. Firefox Desktop 140 и новее. Валюты и криптовалюты в компактном окне на панели браузера: несколько строк для сравнения, поиск, перестановка и отмена удаления, русский и английский интерфейс, светлая и тёмная темы.

Курсы: Frankfurter, Binance и Kraken. Расчёты выполняются локально с точностью до 50 значащих цифр. Суммы и настройки не отправляются разработчику; сторонние API получают обычные сетевые метаданные. Подробности: [PRIVACY.md](../PRIVACY.md).

## Установка

[Скачайте релиз](https://github.com/noumenonnn/numera-widget/releases/tag/v1.0.8), распакуйте `numera-1.0.8.zip`, откройте Firefox → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» и выберите `manifest.json`. Установка временная; для постоянной установки нужна подпись Mozilla. Публикация в AMO ещё не выполнена.

## Сборка

Node.js 24.15.0, npm 11.6.1:

```sh
npm ci
npm run verify
npm run package
npm run package:source
```

Архив расширения и отдельный архив исходников находятся в `artifacts/`. Описание для магазина: [STORE_LISTING.md](STORE_LISTING.md), инструкция подачи: [PUBLISHING.md](PUBLISHING.md).

Курсы справочные, зависят от доступности источников и могут устаревать. Не используйте их как торговые котировки. Расширение не работает в приватных окнах.
