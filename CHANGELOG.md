# Changelog

## 1.0.9 — 2026-11-16

- Add a Chrome 120+ Manifest V3 build and a separate store submission archive.
- Convert selected prices on HTTP(S) pages into the main currency, including while the popup is closed.
- Recognize country names, abbreviations, and common spelling variants in currency input; offer choices for ambiguous currencies.
- Refine the unified converter, currency picker, quick rates, refresh feedback, Undo, and reduced-motion behavior.
- Improve background worker recovery, action replay, cached quote validation, and rate timestamps.
- Update the extension icon, repository screenshots, Firefox installation link, and store listing materials.
- Package both browser builds and reviewer sources with SHA-256 checksums.

## 1.0.8 — 2026-11-04

- Improve rate validation, retry scheduling, permission recovery, and cached quote handling.
- Harden reconnection and action replay with persisted deduplication.
- Improve precise input handling, keyboard focus, row controls, Undo, and wheel interaction.
- Reduce unnecessary UI updates and optimize local image assets.
- Add regression coverage and reproducible release checks.
- Prepare clean runtime and reviewer source archives, store descriptions, privacy documentation, and repository CI.

Initial local development baseline. Earlier development archives were not published releases of this repository.
